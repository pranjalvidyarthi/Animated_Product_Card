# 🛍️ Animated Product Card

A modern and interactive **Animated Product Card** built using **HTML, CSS, and JavaScript**.

The project focuses on creating a visually appealing product-card UI with smooth animations, interactive elements, and a responsive design.

* ⚡ Lightweight and fast

## 🎯 How It Works

The project combines HTML, CSS and JavaScript to create an interactive product-card experience.

### HTML

HTML provides the structure of the card, including:

* Product image
* Product name
* Product description
* Price
* Rating
* Action buttons

### CSS

CSS handles the visual appearance and animations:

* Card layout
* Hover effects
* Transitions
* Shadows
* Product image animations
* Button animations
* Responsive design

### JavaScript

JavaScript adds interactivity to the card.

It can be used for features such as:

* Add to cart
* Favorite/wishlist button
* Quantity changes
* Product selection
* Dynamic UI updates

## 🎨 Customization

You can easily customize the product card.

### Change Product Image

Replace the product image inside the `assets` folder:

```text
assets/product.png
```

Then update the image source in `index.html`:

```html
<img src="assets/product.png" alt="Product">
```

### Change Product Name

```html
<h2>Product Name</h2>
```

### Change Price

```html
<span class="price">$99.99</span>
```

### Change Colors

Modify the CSS variables or color properties in `style.css`:

```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    --background: #f8fafc;
}
```
